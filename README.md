# LasLaz Editor — Descargas

Repositorio **público solo de descargas**. El código fuente vive en un repositorio privado;
aquí únicamente se publican los instaladores oficiales para Windows x64.

## Descargar la última versión

1. Abre la sección **[Releases](../../releases/latest)**.
2. Descarga `LasLaz-Editor-Setup-<versión>.exe`.
3. Ejecuta el instalador (no requiere permisos de administrador).

La aplicación incluye un botón **Buscar actualizaciones** en el menú del usuario
(icono de perfil, arriba a la derecha): consulta este repositorio, detecta la
versión más reciente, la descarga con verificación SHA-256 y se actualiza sola.
